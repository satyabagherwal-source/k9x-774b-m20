# Authoritative External Sources Registry

## 1. Governance Policy
Only sources cataloged in this registry are recognized as authoritative for ecosystem adaptation. Third-party tutorials, opinionated medium articles, and unverified forums are strictly advisory and cannot trigger architectural changes.

---

## 2. Tracked Ecosystem Technologies

### 1. Astro
- **Technology**: Modern Static & Island Web Framework
- **Official Documentation**: `https://docs.astro.build/`
- **GitHub Repository**: `https://github.com/withastro/astro`
- **NPM Package**: `astro`
- **Current Canonical Major**: `5.x`
- **Update Frequency**: Bi-weekly check
- **Severity Classification**: Major = High Impact (Review Required); Minor/Patch = Medium Impact (Automated test verification)

### 2. Tailwind CSS
- **Technology**: Utility-First CSS Framework (v4 Engine)
- **Official Documentation**: `https://tailwindcss.com/docs`
- **GitHub Repository**: `https://github.com/tailwindlabs/tailwindcss`
- **NPM Packages**: `tailwindcss`, `@tailwindcss/vite`
- **Current Canonical Major**: `4.x` (CSS-first `@theme` paradigm)
- **Update Frequency**: Bi-weekly check
- **Severity Classification**: Major/Minor = High/Medium Impact (CSS syntax verification required)

### 3. Vercel Platform & Build System
- **Technology**: Cloud Hosting & Edge Deployment
- **Official Documentation**: `https://vercel.com/docs`
- **Framework Preset**: `astro`
- **Configuration Spec**: `vercel.json`
- **Update Frequency**: Monthly check

### 4. Node.js & npm
- **Technology**: JavaScript Runtime & Package Manager
- **Official Documentation**: `https://nodejs.org/api/`
- **Canonical LTS / Minimum**: `>= 18.0.0` (Active Recommended: 20+ / 22+ / 26+)
- **NPM**: `>= 9.0.0`

### 5. TypeScript
- **Technology**: Typed JavaScript Compiler
- **Official Documentation**: `https://www.typescriptlang.org/docs/`
- **NPM Package**: `typescript`
- **Current Canonical Major**: `5.x`

### 6. Vite
- **Technology**: Next-Generation Frontend Tooling
- **Official Documentation**: `https://vite.dev/guide/`
- **GitHub Repository**: `https://github.com/vitejs/vite`
- **NPM Package**: `vite`

### 7. Web Standards & SEO
- **HTML / DOM**: WHATWG HTML Standard (`https://html.spec.whatwg.org/`)
- **CSS Specifications**: W3C CSS Working Group (`https://www.w3.org/Style/CSS/`)
- **Web Vitals & Search**: Google Search Central (`https://developers.google.com/search/docs`) & Web.dev
