# Cognitive Load and Accessibility Contrast Thresholds for Novice Users

Users experiencing visual impairment or high cognitive friction require minimum 4.5:1 contrast ratios and progressive disclosure of complex tooling to prevent cognitive abandonment. Implements user persona need mapping.
