# Astro 5 Architecture, Zero-JS Islands & SEO Engineering

> Canonical reference: `AI-Builder-Brain/03_SKILLS/astro-architecture-and-seo.md`  
> Purpose: Technical standard for structuring Astro 5 applications for high performance, zero client-side JavaScript overhead, and flawless search engine indexing.

---

## 1. Core Architectural Pillars

Astro is engineered for content and tool performance through HTML-first compilation and selective hydration.

### Key Architectural Tenets:
1. **Zero-JS Static HTML by Default**:
   Pages compile to pure, semantic HTML at build time (`output: 'static'`). Interactive scripts are isolated only where necessary.
2. **Component Islands**:
   Dynamic client-side components (React, Svelte, Vue, or Vanilla JS) are isolated into independent islands using explicit client directives (`client:load`, `client:visible`, `client:idle`).
3. **SEO Native `<head>` Management**:
   Full direct control over metadata, canonical tags, Open Graph meta, and JSON-LD schema markup without client-side routing hydration latency.

## 2. Directory Structure Standards

Every standard project generated by AI-Builder-Brain must strictly maintain this layout:

```
src/
├── components/         # Reusable presentation and UI components (.astro)
│   ├── Header.astro
│   ├── Hero.astro
│   └── Footer.astro
├── layouts/            # Page shell layouts
│   └── BaseLayout.astro
├── pages/              # File-based routing
│   ├── index.astro
│   └── 404.astro
└── styles/             # Global CSS and Tailwind v4 theme definitions
    └── global.css
```

## 3. SEO Checklist & Trailing Slash Invariant

- **Single `<h1>`**: Exactly one meaningful `<h1>` per page reflecting the primary search intent.
- **Canonical URLs**: Every page must output an absolute canonical tag:
  ```html
  <link rel="canonical" href={canonicalURL} />
  ```
- **The Trailing Slash Invariant**:
  Edge hosting platforms (Cloudflare Pages, Vercel) default to directory routing (`/path/`). To prevent 301 redirection ping-pong and canonical loops in Google Search Console:
  ```javascript
  // astro.config.mjs
  export default defineConfig({
    trailingSlash: 'always',
    build: { format: 'directory' }
  });
  ```
- **Semantic HTML5 Elements**: Use `<header>`, `<main>`, `<nav>`, `<article>`, `<section>`, `<aside>`, and `<footer>` elements rather than generic `<div>` tags.
- **Web Vitals Optimization**:
  - **Zero Cumulative Layout Shift (CLS = 0)**: Always define explicit aspect ratios or minimum heights for banners, hero graphics, and interactive widgets.
  - **Sub-Second Largest Contentful Paint (LCP < 1.2s)**: Preload primary web fonts and hero assets in the layout `<head>`.
  - **Interaction to Next Paint (INP < 200ms)**: Keep UI main thread unblocked; offload heavy computations to Web Workers or requestAnimationFrame.
